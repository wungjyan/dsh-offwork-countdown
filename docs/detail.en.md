The pill walks a workday with you:

| State | What the pill says |
| --- | --- |
| Shift started | "09:00" with a **Clock in** button |
| Counting down | "Ends 18:00" and the time left |
| Nearly done | The countdown switches to a warning colour |
| Time to leave | The card fills with colour, breathes and shakes, with a **Got it** button |
| Off the clock | The next shift, such as "Starts tomorrow at 09:00" |

Change the settings in the form on this page; each change applies at once, with nothing to save.

The clock-out reminder does **not** depend on clocking in: someone who forgot still gets reminded. Only switching the pill off hides it completely.
